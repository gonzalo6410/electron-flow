SEARCH AND BENZYNE REVIEW BRIEF (7 Nov 2026; read /home/claude/agents/BRIEF-common.md first)

What is new (yours to review):
- The compound picker is gone. One search box takes a common name, a systematic name or a SMILES (web/index.html, the "search" part of web/app.js, core/names.js). Suggestions appear as you type (up to eight; arrow keys, Enter, Escape; "add" on a row, or shift-Enter, puts the compound beside what is on screen). Enter takes the highlighted row, else a name equal to the text, else the text as a SMILES, else the first suggestion. A bare ion gets counter-ions (Na+ for each minus, Cl- for each plus). After an edit or a move the box names what is on screen if the list has it (a hash of the skeleton: which atoms are joined and each piece's charge).
- The names: web/names.json.gz, built by tools/build-names.mjs from the chemicals Python package's PubChem lists (about 67,000 compounds with synonyms), each run through the engine; compounds the engine cannot do (an element not in the table, too slow) are kept with the reason so a search says why. Stereoisomers are merged (the engine ignores stereo). The page cannot reach the internet, so this file is all there is.
- The ring rule (core/lewis.js, test/rings.js) and the geometry of a two-neighbour atom in a small ring (core/geometry.js): benzyne now exists (two structures), and cyclohexyne, arynes of pyridine and naphthalene; pyridine and pyridazine unchanged; 1,2-cyclohexadiene refused.
